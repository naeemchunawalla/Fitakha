FITAKHA WEBSITE — VERSION 19
Includes the latest coach offerings, U.S. English spelling updates, team profiles,
logo, optional assessments, and expert categories.

VIEW LOCALLY
Extract this ZIP. Open a terminal in the Fitakha-Website folder and run:
  python -m http.server 8000
Visit http://localhost:8000 in your browser.

HOSTING
Upload the folder contents to a static website host. Configure private access
separately; ChatGPT Site access restrictions are not part of this export.

FEATURE STATUS
Registration, shared tracking, and coach tools remain coming-soon features.
Coach interest buttons open email drafts. Trivia progress is browser-local.
Health and posture answers stay within the current visit.
Stock photos, fonts, and linked videos require internet access. Stock photo
licenses/model releases have not been fully audited for commercial marketing.
