FITAKHA WEBSITE — SOURCE EXPORT

Includes the HTML, CSS (inside the HTML pages), JavaScript, logo, and posture illustrations from the latest site version built in this conversation.

PREVIEW
Extract the ZIP. Open index.html for a quick look.
For working root-relative navigation, serve this folder locally:
  python -m http.server 8000
Then open http://localhost:8000 in your browser.

HOSTING
Upload the contents of this folder to a static web host. No build step is required.
Private access on the current hosted site is provided by ChatGPT Sites. These downloaded files do not include access control. Configure privacy on your chosen host before uploading if needed.

CURRENT LIMITATIONS
- ChatGPT sign-in endpoints are supplied by ChatGPT Sites and will not work on a generic local/static host.
- Fitakha registration, personalized account storage, bookings, checkout, and cross-device tracking are not implemented.
- Trivia uses browser local storage. Health and posture answers are kept only in the current visit.
- External stock photos, Google Fonts, video searches, and evidence links require internet access; those external assets are not bundled.
- Health/posture logic is a limited educational starter, not a validated clinical recommendation system.
- The most recent registration-first suggestion for chronic conditions was discussed but has not been implemented in this exported version.
